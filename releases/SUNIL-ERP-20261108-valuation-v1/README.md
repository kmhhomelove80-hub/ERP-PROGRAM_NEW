# 선일 ERP 재고금액 기능 통합 업데이트

버전: **SUNIL-ERP-20261108-valuation-v1**
기준: 2026-11-07 최종 통합 업데이트. 이전 개선을 포함합니다.

## 추가한 기능

- Y09 ERP 추출 파일의 재고금액을 선택 항목으로 저장합니다. 기존 금액 없는 자료도 등록할 수 있습니다. 새 DB 구조는 `0016_reconciliation_inventory_amount`의 빈 값 허용 금액 필드 하나입니다. 기존 자료에 금액을 임의로 채우지 않고 재고·예약 수량을 변경하지 않습니다.
- 위치별 재고에 **재고금액(ERP 기준 추정·원)**을 표시합니다. ERP 품목 금액 ÷ ERP 현재고 × 위치 현재고이며, 위치별 원 단위 반올림값을 합산합니다. 현재고에 포함된 할당분은 다시 차감하지 않습니다.
- 입고 예정분과 Y09 외 창고는 금액 합계에서 제외합니다. 금액 누락·ERP 현재고 0 이하·음수 금액은 계산 불가로 표시합니다. 유효한 0원과 누락은 다릅니다. 계산 불가 행이 있으면 합계는 일부 재고만의 추정 금액입니다. 공식 회계 평가액이 아닙니다.
- 필터된 검색 전체 금액과 ERP 기준 시각을 표시합니다. 기존 수량 합계·열 필터를 유지합니다. 엑셀의 기존 12열 뒤에 추정 금액·계산 상태·ERP 금액 기준 시각을 추가했습니다. ERP 대조 상세와 대조 엑셀에는 품목별 원본 금액도 표시합니다.
- 새 사용 설명서는 공개 배포에 포함하지 않습니다. 설명서 갱신은 별도로 제공하는 비공개 파일을 사용합니다.

## 금액을 표시하려면

업데이트 뒤 **금액이 포함된 Y09 ERP 원본을 대조 자료로 다시 등록**하세요. 원본의 실제 기준 시각을 입력합니다. 예전 등록 자료는 금액을 저장하지 않았으므로 설치만으로 표시되지 않습니다. 최신 Y09 자료에 금액이 없으면 오래된 금액으로 대신 계산하지 않습니다. 등록은 관리 재고 수량을 덮어쓰지 않습니다.

## 업데이트 후 확인

설치는 관리자에게 제공된 적용 절차를 따르세요. 공개 문서에는 회사의 설치 위치·접속 정보·관리자 실행 명령을 포함하지 않습니다.

- 금액 포함 Y09 자료를 실제 원본 기준 시각으로 다시 등록합니다.
- 위치별 금액과 필터 합계·엑셀을 비교합니다.
- 새 사용 설명서는 별도로 제공된 비공개 파일을 확인합니다.
- 실제 거래와 회사 프린터 출력은 현장에서 확인합니다.
