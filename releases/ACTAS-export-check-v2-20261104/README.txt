Actas Y02·Y09 파일 추출 검증본 v2 — 2026-11-04

v1의 정수 전용 검사 때문에 정상 소수/음수/공란 자료가 중단되던 부분을 수정했습니다.
소수와 음수는 정상 원본 값으로 인정합니다. 반올림·절삭하지 않습니다.
공란은 0으로 바꾸지 않고 원본 공란으로 보관합니다.
원본 XLS 파일은 수정하지 않고 SHA256·품목 수·소수/음수/공란 건수·예시 행을 기록합니다.
공란이 있으면 전체 합계는 미확정(null)이며, 공란 제외 합계는 별도 문자열로 기록합니다.
integer_quantity_compatible는 기존 정수형과의 수량 호환 정보일 뿐, 소수가 오류라는 뜻이 아닙니다.

이 도구는 Actas 창고 조건 입력·조회(Ctrl+R)·Excel 저장(Ctrl+E)을 실제 실행합니다.
SUNIL ERP 등록/DB 직접 연결/실제 재고·예약·입출고 변경/서비스 중지/설정 변경은 하지 않습니다.
별도 패키지나 .NET3.5 설치는 필요하지 않습니다.
창고 입력 방식은 사용자가 영주제품창고로 변경됨을 확인한 v1과 같습니다.
실제 무인 자동 조회 완료 판정은 아직 검증되지 않았고, 창고별 완료 확인은 담당자가 합니다.

1. 압축 안의 actas-export-check-v2 폴더를 C:\SUNIL\updates 에 둡니다.
   v1 폴더/기존 XLS/result.json은 보관합니다. v1은 다시 실행하지 않습니다.
2. Actas의 기존 저장창 등을 취소로 닫고 현재고 현황을 엽니다.
   품목검색은 비우고 대/중/소 분류 등은 전체로 맞춥니다. 창고 코드 칸을 클릭해 선택해 둡니다.
3. Actas와 같은 Windows 계정·권한 수준의 PowerShell에서 실행합니다.

& 'C:\SUNIL\ERP\.venv\Scripts\python.exe' 'C:\SUNIL\updates\actas-export-check-v2\actas_export_check_v2.py'

4. 준비되면 START 또는 start를 입력합니다. Enter만 누르면 취소합니다.
5. 도구가 Y02를 입력하고 조회합니다. Actas에서 Y02와 해당 창고명, 표 갱신을 확인합니다.
   조회가 끝나면 PowerShell로 돌아와 Y02 또는 y02를 입력합니다. 파일이 새 폴더에 저장됩니다.
6. Y09도 조회 완료 후 같은 방식으로 Y09 또는 y09를 입력합니다.
   다른 단계의 코드를 입력하면 설명하고 재입력을 받습니다. Enter로 중단할 수 있습니다.
7. 완료 화면에 표시된 runs\실행번호\result.json을 개발 담당자에게 전달합니다.
   필요하면 같은 폴더의 Y02.xls/Y09.xls를 함께 전달합니다. 자동 업로드는 하지 않습니다.

실행 중 확인 단계 외에는 Actas에서 키보드·마우스를 조작하지 마세요.
Windows를 잠그거나 원격 데스크톱을 끊지 마세요. 다른 Actas 수집 도구와 동시에 실행하지 않습니다.
소수/공란이 있어도 구조가 정상이면 Y09 단계까지 진행합니다.
잘못된 문자/무한대/중복 코드 등은 문제 행·열을 기록하며 중단합니다.
이 경우 저장된 파일의 경로·해시와 오류 메시지도 result.json에 남습니다.
기존 파일은 덮어쓰지 않습니다. 두 창고 코드·수량이 같으면 확인 필요 상태로 중단합니다.
보안 프로그램 경고나 예상치 못한 창이 나오면 반복 실행/허용 설정 없이 화면을 전달합니다.
