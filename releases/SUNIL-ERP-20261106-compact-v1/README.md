# 데이터 표 중심 화면 개선

배포: SUNIL-ERP-20261106-compact-v1
이전 통합 v3 / bridge-v1 / inbound-v1 / stocktake-v1 / receive-v1에서 적용 가능한 통합 업데이트입니다. 실사·조정, 정리 판정, 생산계획 읽기 개선, 입고 LIST 5열 전달·실제 입고와 기존 수주 연동을 유지합니다.

## 반영 사항

- 상단 고정 메뉴를 한 줄로 압축하고 생산계획조회·입고 LIST를 가로 배치합니다. 로고·메뉴·버튼 글자와 여백을 줄입니다. 데스크톱 검증에서 상단 높이는52px입니다.
- 본문은 화면 너비를 활용하며 제목·관련 링크·도움말을 한 줄로 모읍니다. 반복 안내는 접어서 확인하고, 중요한 경고·검증 오류는 유지합니다. 처리 완료 알림은 표를 밀지 않는 작은 알림으로 표시합니다.
- 표의 높이를 고정 비율로 제한하지 않고, 검색·처리 영역 아래에 남은 화면 높이로 계산합니다. 열 제목은 고정하고 표 안에서 스크롤합니다. 작은 결과는 내용 높이만 사용합니다.
- 출고 화면의 처리 구분·출고 시각·확인 체크·처리 버튼을 필터 바로 아래에 모았습니다. 필터 전체 합계·이번 처리 수량·선택 행 수를 한 줄로 표시합니다. 내부 긴 주문 UUID는 목록에서 제외하고 상세 화면에서 확인합니다.
- 실제 출고 시각은 한국 현재 시간으로 기본 표시합니다. 사용자가 수정하지 않았다면 최종 등록 때 서버 현재 시간을 사용합니다. 직접 수정한 과거 출고 시각은 유지하며, 비워두면 현재 시간으로 처리합니다. 일반 출고와 대체 출고에 적용합니다. 미래 시각·입고 미완료·선택 범위 변경 등 기존 검증은 유지합니다.
- 표 아래쪽에 가까워지면 다음 자료를 미리 불러옵니다. 정상 동작 중에는 더 보기 버튼을 숨기고 조회 상태만 표시합니다. 실패하면 자동 반복을 멈추고 다시 시도 버튼을 제공합니다. 필터·정렬·선택과 중복 행 방지 기능을 유지합니다.
- 재고 조회의 제목·엑셀 내보내기, 검색·상태, 합계 정보를 압축하고 기준 안내를 접습니다.
- 입고 LIST의 파일 선택·가상 예제 버튼 간격을 확보하고 업로드 영역 높이를 줄입니다. 파일을 불러온 뒤에는 불필요한 안내를 줄이고, 코드별 추천 위치 상세와 편집 안내를 펼쳐 볼 수 있도록 합니다. 추천 위치 일괄 적용은 바로 누를 수 있습니다.
- 입고·실사 등 미리보기 확인 화면은 최종 처리 도구를 표 위에 배치하고 원본 입력 편집은 펼쳐서 사용합니다. 아직 검증되지 않은 입력 오류는 숨기지 않습니다.
- 모바일 메뉴·표 가로 스크롤과 터치 크기를 유지하면서 공간을 줄입니다. 화면 크기·도움말 펼침·파일 불러오기·추가 행 조회에 맞춰 표 높이를 다시 계산합니다. 인쇄에서는 화면 높이 제한을 적용하지 않습니다.

가상 출고 자료로 측정한 표 점유율은 1920×1080에서 약77.9%, 1366×768에서 약68.9%입니다. 실제 결과는 경고·열린 도움말·입력 오류·화면 크기·자료 길이에 따라 달라집니다.

## 현장 확인

1. 상단의 생산계획조회·입고 LIST 가로 배치와 표 높이를 확인합니다.
2. 재고·출고·거래 이력 등에서 표 안을 스크롤해 버튼 없이 추가 조회되는지 확인합니다. 네트워크 오류 시에는 다시 시도를 사용하세요.
3. 출고 도구가 필터 아래 있는지, 시각이 한국 현재 시간인지, 직접 수정한 시각이 유지되는지 확인합니다. 등록 시각의 기준은 서버 시계이므로 서버 Windows 시간이 정확해야 합니다.
4. 선택 행·필터 전체·합계수량을 확인한 뒤 실제 처리할 건만 확정합니다. 기능 시험을 위해 가상 입출고를 실제 서버에 등록하지 마세요.
5. 입고 LIST 파일 버튼 간격, 추천 위치 상세 펼침, 기존 5열 전달과 최종 입고 동작을 확인합니다.
6. 실제 휴대폰에서도 메뉴·필터·선택·표 스크롤과 인쇄 결과를 확인합니다.
