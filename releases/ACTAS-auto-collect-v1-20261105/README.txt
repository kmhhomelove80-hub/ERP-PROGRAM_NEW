Actas 자동 수집 검증 v1

수신한 Y09 조회 측정에서 대기 커서와 응답 지연 뒤 정상 복귀를 확인했습니다.
이 도구는 두 창고 각각의 조회 신호를 따로 관찰합니다. 고정 시간 후 성공 처리하지 않습니다.
창고명은 작은 글씨를 확대해 PC의 Windows OCR로 판독합니다.
실제 서버에서 자동 수집 경로를 확인하는 시험본이며 ERP 등록·정기 실행은 하지 않습니다.

실행
1. 압축 안 actas-auto-collect-v1 폴더를 기존 업데이트 자료 보관 위치에 넣으세요.
2. Actas에 로그인하고 현재고 현황을 열어 두세요. 검색·분류 조건은 전체, 저장창은 닫으세요.
3. Run-Auto-Check.cmd를 실행하고 start를 한 번 입력하세요.
4. 이후 마우스·키보드·화면 전환을 조작하지 마세요. 직접 창고 칸을 클릭할 필요가 없습니다.
5. 도구가 Actas를 활성화해 창고 칸 선택 → Y02 입력·명칭 확인 → 조회·저장 → Y09 입력·명칭 확인 → 조회·저장을 진행합니다.

판정
- 제목과 창고명이 하나로 정확히 읽혀야 코드 칸을 클릭합니다.
- 클릭한 입력란의 실제 코드와 읽힌 창고명이 맞아야 새 코드를 입력합니다.
- 기존에 검증한 실제 키 입력과 Tab 확정 방식을 사용합니다.
- Y02 영주제품창고, Y09 부산창고를 각각 확인합니다.
- 검색·분류 영역은 현장에서 전달받은 빈 조건 화면의 지문과 일치해야 합니다. 창고 코드·이름 영역은 비교에서 제외합니다.
- 화면 크기·배율·표시 상태가 바뀌어도 조건 검증이 중단될 수 있습니다. 임의로 검증 기준을 갱신하지 않습니다.
- 창고마다 조회 시작 이후 대기 커서와 창의 응답 지연을 함께 관찰해야 합니다.
- 두 신호가 해제되고 안정적으로 정상인 상태가 유지돼야 저장 단계로 갑니다.
- 각 창고는 최대 180초까지 따로 기다립니다. 제한 시간 경과는 성공이 아닙니다.
- 재고 표의 이미지가 같다는 이유만으로 실패하지 않습니다. 같은 창고를 재조회하면 값이 그대로일 수 있습니다.
- 다른 화면으로 바뀌거나 마우스가 Actas 밖으로 이동하면 중단합니다.
- 정상 저장창과 새 실행 폴더만 사용하며 기존 파일을 덮어쓰지 않습니다.
- 두 파일의 내용과 품목 구성이 같은 경우에는 검토가 필요하다고 중단합니다.
- 소수·음수·공란은 원본 그대로 보존합니다.

결과
이 폴더의 runs 안 새 실행 폴더에 result.json과 Y02.xls·Y09.xls를 저장합니다.
실패하더라도 result.json에 판독 결과와 중단 위치를 기록합니다.
완료 또는 실패 후 result.json을 전달하세요. 완료했다면 두 XLS 파일도 함께 전달하세요.
정상 완료 상태는 automatic_exports_checked_operator_review_required 입니다.
이는 자동 수집 파일 검사 완료이며 현장 검증이나 ERP 등록이 완료됐다는 뜻이 아닙니다.
사람이 확인했다는 기록을 만들지 않습니다. 기존 v5 등록 도구에 이 결과를 넣지 마세요.
검증 후 자동 수집과 대조 등록을 연결하는 별도 단계가 필요합니다.

동작 범위
창고 필터 변경, 조회 단축키, 엑셀 저장만 실행합니다.
DB 접속·비밀키 읽기·ERP 프로그램 교체·서비스 변경·예약 작업 생성은 하지 않습니다.
화면은 외부로 전송하지 않습니다. OCR용 조건 화면은 임시 폴더에서 읽고 삭제합니다.
한국어 OCR이 없으면 설치하거나 설정을 바꾸지 않고 중단합니다.
정기 실행은 월~금 09:00~17:00 매시 정각과 공휴일 제외를 목표로 준비 중이며 아직 활성화하지 않았습니다.
