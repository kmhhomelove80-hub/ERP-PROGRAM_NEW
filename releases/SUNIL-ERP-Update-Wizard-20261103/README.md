## 실행 순서

1. 기존 ERP 서버에 평소 사용하는 Windows 계정으로 로그인하고 ERP 접속이 정상인지 확인합니다.
2. ZIP을 다운로드하고 압축을 풉니다.
3. 안의 `SUNIL-ERP-Update-20261103.exe`를 더블클릭합니다. 관리자 권한 승인도 같은 계정으로 진행합니다. 다른 관리자 계정의 암호를 요구하면 취소하고 화면을 알려 주세요.
4. **사전 점검**을 누릅니다. 이 단계는 프로그램을 교체하거나 서버를 중지하지 않습니다. 점검 기록은 생성합니다. 오류가 나오면 진행을 멈추고 화면과 로그를 알려 주세요.
5. 점검을 통과하면 직원들에게 잠시 저장·처리를 멈춰 달라고 알립니다. 마법사의 확인란을 체크하고 **업데이트 시작**을 누릅니다.
6. 완료될 때까지 창을 닫거나 컴퓨터를 끄지 않습니다. 백업 크기에 따라 시간이 걸릴 수 있습니다.
7. 완료 메시지가 나오면 브라우저에서 `Ctrl+F5`로 새로고침합니다. 메뉴가 하나씩만 열리는지, 제품명·사양 조건 검색이 동작하는지, 운영 점검 합계가 일치하는지 확인합니다. 확인 후 업무를 재개합니다.

백업, 파일 반영, 화면 파일 수집, 재시작과 확인을 자동으로 처리합니다. 기존 데이터·계정·설정·비밀키를 보존하도록 구성했습니다. 이번 버전은 DB 구조를 변경하지 않으며 DB 초기화·재이관·자동 DB 복원을 하지 않습니다. 외부 접속 설정도 변경하지 않습니다.
