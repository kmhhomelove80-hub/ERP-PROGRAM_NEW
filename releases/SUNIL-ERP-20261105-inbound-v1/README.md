# 입고 LIST · 재고 스크롤 · 출고 수량 업데이트

2026년 11월 5일. 기존 통합 v3 또는 bridge-v1 설치 서버용입니다. 데이터베이스 구조 변경이나 별도 패키지 설치가 없습니다. 실제 재고를 자동 변경하지 않습니다.

## 반영 내용

- 생산계획조회 오른쪽 입고 LIST 메뉴. 입고 관리 모두 가능 권한에서 사용합니다.
- CP949 탭 텍스트를 포함한 XLS, UTF-8, XLSX, XLSM, RAW 우선 읽기. 상세 행 유지, 합계 행 제외.
- 32+32 자동 분할, 합계 불일치 시 복사·다운로드·인쇄 차단. 분할 행별 비고, 체크 삭제, 직전 삭제 취소, 남은 수량 재계산.
- Y09 입고 완료 현재고가 많은 기존 위치를 ERP 코드별 추천. 한 번 일괄 적용하며 직접 입력하거나 지운 비고는 보호. 위치가 없으면 코드별로 한 번 지정합니다. 실제 재고 위치를 변경하지 않습니다.
- ERP용 5열 텍스트와 Excel HTML 동시 복사. 6열 엑셀, 총수량 병합·숨김 반영.
- 한국 날짜 기본값, 수정 가능. A4 세로 인쇄: 품목코드 / 품목명 / 수량 / 총수량 / 비고. 규격 제외, 총수량 항상 표시, 여러 페이지에 헤더 반복.
- 재고 조회에서 페이지 번호 대신 아래로 스크롤하여 추가 조회. 검색·정렬 유지.
- 예약 / 선택 출고 표 위에 필터 전체 합계와 이번 처리 수량. 전체 필터 처리는 다른 페이지도 포함하고, 체크 처리는 현재 선택된 행 기준입니다. 기존 입고 확인·예약 검증은 유지합니다.
- 모바일 하단 재고조회·재고이동·매뉴얼 고정 메뉴 제거. 상단 메뉴에서 접근합니다.
- 기존 수주 연동 유지. 수주 프로그램에서 새 탭을 여는 동작은 별도 프로그램 수정 대상입니다.

## 서버 업데이트 순서

1. 압축을 풀어 이 README와 Update-Erp.py가 있는 폴더를 `C:\SUNIL\updates\SUNIL-ERP-20261105-inbound-v1`에 둡니다. 폴더가 이중으로 겹치지 않게 확인합니다.
2. 평소 서버를 실행하는 같은 Windows 계정의 관리자 PowerShell에서 사전 점검합니다.

```powershell
& 'C:\SUNIL\ERP\.venv\Scripts\python.exe' 'C:\SUNIL\updates\SUNIL-ERP-20261105-inbound-v1\Update-Erp.py' check
```

3. 통과 후 직원의 저장·출고·이동 작업을 잠시 멈추고 실행합니다.

```powershell
& 'C:\SUNIL\ERP\.venv\Scripts\python.exe' 'C:\SUNIL\updates\SUNIL-ERP-20261105-inbound-v1\Update-Erp.py' apply --work-paused
```

4. 완료되면 브라우저에서 Ctrl+F5로 새로고침합니다. app 폴더를 수동으로 덮어쓰지 마세요. 실패하면 출력된 기록 폴더를 보존하고 다음 단계를 진행하지 마세요. 기존 백업·복구 업데이터를 그대로 사용합니다.
5. 기존 수주 연동, 재고 검색과 스크롤, 예약 화면에서 필터·선택 합계, 입고 LIST 메뉴를 확인합니다.
6. 가상 예제 또는 복사본 재고이동 파일로 변환하고 위치 적용·수동 비고 보호·분할 삭제와 취소를 확인합니다.
7. ERP용 복사 후 실제 대상 Actas 입력 화면에 붙여넣어 5열과 수량·비고를 확인하세요. 이 동작은 실제 ERP에서 최종 검증해야 합니다. 테스트 자료를 ERP에 저장하지 마세요. 실제 브라우저 PDF와 엑셀 병합은 자동 검사합니다. 종이 출력은 프린터에서 확인합니다.
