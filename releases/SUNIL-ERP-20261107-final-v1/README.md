# 선일 ERP 최종 개선 통합 업데이트

버전: **SUNIL-ERP-20261107-final-v1**
기준: 2026-11-06 공동 작업·회사 프린터 배포본. 기존 기능을 포함하는 누적 업데이트입니다.

## 이번 추가 개선

- 위치별 재고의 ITEM No.·사양·위치·상태·현재고·할당·가용량·출하대기에 머리글 필터를 추가했습니다. 복수 값 선택, 포함 검색, 수량 범위, 열별 해제와 전체 조건 해제를 지원합니다. 표시 중인 50행뿐 아니라 전체 검색 결과를 조회하며 합계·엑셀 내보내기·자동 스크롤에 같은 조건을 유지합니다. 휴대폰은 기존 재고 카드 위에 열 필터 줄을 제공합니다.
- 고객 양식 피킹리스트의 위치별 피킹리스트 링크 옆에 피킹 주문 이력을 추가했습니다.
- 미리보기 부족표와 저장 주문의 현재 부족 행에 대체품 등록을 추가했습니다. 미리보기에서는 확인창을 거쳐 현재 배정 결과를 예약하고 대체 등록으로 이동합니다. 요청 코드·현재 부족 수량을 자동 입력하며 일부 수량만 배정할 수 있습니다. 등록 후 해당 피킹으로 돌아와 남은 부족 수량을 확인합니다. 기존 대체품 배정 메뉴는 빌림·상환 상세 흐름을 유지합니다. 대체 등록 자체는 예약이며 실출고가 아닙니다.

## 포함된 기존 개선

입고 LIST 저장·누적·공동 배치 기록·최종 입고·숨김/복구, 예약·선택 출고의 머리글 필터, 회사 서버 프린터 대기열과 Windows 인쇄 작업자, 입고 자료 끝자리 소수점 처리, 화면 압축·자동 스크롤·현재 출고 시각, 재고 실사/조정과 되돌리기, 정리 기존 유지 판정, 생산계획 읽기 개선을 유지합니다.

입고 LIST의 소수 수량은 저장·검토할 수 있지만 기존 실입고는 양의 정수 조건을 유지합니다. 저장한 파일을 새 작업으로 다시 불러오면 별도 목록이므로 중복 입고를 확인하세요. 실제 비고/최종 전달의 다섯 번째 항목은 로케이션입니다.
