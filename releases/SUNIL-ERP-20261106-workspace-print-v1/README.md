# 선일 ERP 추가 개선 통합 업데이트

버전: SUNIL-ERP-20261106-workspace-print-v1

## 반영 기능

1. 입고 LIST 저장·모바일 배치 기록·관리자 이어서 작성·최종 입고. 일부만 기록돼도 관리자가 완성할 수 있습니다. 직원 계정에 새로 추가된 `입고 LIST 배치 기록` 권한은 위치·배치 기록만 허용합니다. 최종 입고는 입고 관리의 모두 가능 권한이 필요합니다.
2. 예약·선택 출고의 상단 검색 영역을 표 머리글 엑셀 방식 필터로 변경. 전체 예약 자료에 대해 프로젝트·SEQ·ERP 코드·위치·입고 상태·수량을 조합합니다. 합계·전체 선택·실제 처리 범위가 동일 조건을 사용합니다.
3. 회사 프린터로 피킹 목록 원격 출력. 출력 요청은 지정된 회사 Windows 서버에서 처리하며 기본은 비활성입니다. 엑셀·PDF 등 일반 프로그램은 별도 VPN·Windows 공유 프린터 연결로 사용합니다. 프린터 및 VPN 설정을 업데이트 중 자동 변경하지 않습니다.

기존 입고 수량 `6.` 형식 오류 수정, 화면 압축·자동 스크롤·출고 시각·실사·생산계획 개선을 포함합니다. 수주량 비교 현황과 피킹 주문 메뉴 명칭 변경은 범위에 포함하지 않았습니다.

## 설치 전

기존 Windows 서버와 동일한 운영 계정의 관리자 PowerShell을 사용하세요. 기존 ERP 가상환경과 PostgreSQL, Caddy 설정을 유지합니다. 업데이트 파일에 실제 재고·사용자 파일·데이터베이스·로그·비밀번호는 포함하지 않습니다.

압축을 풀어 아래처럼 내부 폴더에 Update-Erp.py가 위치하도록 놓습니다.

`C:\SUNIL\updates\SUNIL-ERP-20261106-workspace-print-v1\Update-Erp.py`

먼저 조회·점검만 실행합니다.

```powershell
& 'C:\SUNIL\ERP\.venv\Scripts\python.exe' 'C:\SUNIL\updates\SUNIL-ERP-20261106-workspace-print-v1\Update-Erp.py' check
```

점검 통과 후 직원의 저장·입고·출고·재고 변경을 멈춥니다. 회사 프린터 작업자를 이미 설치했다면 프린터 안내에 따라 중지·비활성화해야 합니다. 이후 적용합니다.

```powershell
& 'C:\SUNIL\ERP\.venv\Scripts\python.exe' 'C:\SUNIL\updates\SUNIL-ERP-20261106-workspace-print-v1\Update-Erp.py' apply --work-paused
```

중지 전·중지 시점 백업, 기존 코드 복구본, 허용된 마이그레이션, 재시작·데이터 비교·백업 검증을 수행합니다. 새 `0015_inbound_work_and_company_print`는 공동 작업·프린터 관리 테이블과 기본 꺼짐의 배치 기록 권한만 추가합니다. 기존 재고·예약 수량을 변경하지 않습니다. `0014`가 없는 지원 버전은 기존 실사 관리 테이블도 함께 추가합니다.

완료 후 브라우저에서 Ctrl+F5로 새로고침합니다. 실패하면 반복 적용이나 데이터베이스 수동 복원부터 하지 말고, 표시된 업데이트 기록을 확인하세요. 표준 도구는 데이터베이스를 자동으로 과거 백업으로 덮어쓰지 않습니다.

## 공동 작업 사용

관리자가 입고 LIST에서 파일을 불러오고 분할·수량을 확인한 뒤 `저장 · 공동 작업`을 누릅니다. 저장 자체로 입고하지 않습니다. 같은 파일 불러오기 작업의 반복 저장은 중복 목록을 만들지 않지만, 파일을 새로 불러오면 별도 목록이므로 중복 등록에 주의하세요.

직원 계정에 `입고 LIST 배치 기록` 권한을 부여하면 모바일에서 실제 위치와 배치 완료를 기록할 수 있습니다. 위치 변경은 배치 확인을 해제합니다. 관리자는 미입력·배치 미완료만 조회하고 나머지를 작성할 수 있습니다. 추천 위치는 참고이며 실제 확인 없이 배치 완료로 처리하지 않습니다.

수정 충돌은 덮어쓰지 않고 안내합니다. 저장 실패 시 입력을 보관한 뒤 새로 조회하세요. 편집한 뒤에는 전체 새로 조회로 최신 기록과 모든 행을 확인한 후 최종 입고합니다. 최종 입고는 1 이상의 정수 수량·실제 위치·배치 확인이 모두 필요합니다. 소수 자료는 저장·확인할 수 있지만 기존 선일 ERP 실입고의 정수 조건을 바꾸지 않습니다.

최종 입고 후 기록을 잠그고 반복 요청을 차단합니다. 숨김은 저장 목록 표시만 바꾸며 실제 재고나 입고 원거래를 취소하지 않습니다. 숨긴 목록에서 복구할 수 있습니다. 실제 입고 취소는 기존 입고 원거래 취소 절차를 사용하세요.

## 공개 배포 범위

공개 저장소와 다운로드 링크는 누구나 열 수 있습니다. 배포 파일은 허용 목록에 있는 프로그램·업데이트 도구·안내만 포함합니다. 기존 runtime.local.json, 암호화된 비밀값, 실제 데이터는 포함하지 않습니다. 운영 웹 서버와 프린터는 회사가 승인한 VPN·접근 통제 안에서 사용하세요. 비공개 저장소 여부와 별개로 권한·인증·서버 업데이트가 필요합니다.
