# 선일 ERP 개발 진도

## 최신 반영 내용

- Y09 ERP 자료의 재고금액 저장과 위치별 추정 금액 표시
- 검색 결과 전체의 금액 합계, 엑셀 금액·계산 상태·기준 시각
- 최신 사용 매뉴얼은 공개 배포에 포함하지 않고 별도로 제공합니다.

## 포함된 기존 기능

- 위치별 재고와 예약 출고의 열 필터
- 입고 LIST 변환·분할·복사·누적·공동 작업·최종 입고
- 피킹 주문 이력 연결과 부족표 대체품 등록
- 회사 프린터 출력 요청과 대기열
- 재고 실사/실사조정·백업·되돌리기
- 재고 정리 기존 유지 판정
- 생산계획 조회·업로드와 표 중심 화면·자동 스크롤

## 확인 상태

프로그램 검사와 실제 운영 적용은 구분합니다. 운영 적용·회사 프린터 종이 출력·외부 접속은 현장 확인 항목입니다. 과거 운영 기록이나 접속 구성은 이 공개 문서에 포함하지 않습니다.

[최신 기능별 진도표](VALUATION_PROGRESS_20261108.md)에서 사용자가 확인할 순서를 볼 수 있습니다.
