# 직원 계정의 대메뉴별 권한

관리 → 직원 계정에서 입고 관리·출고 관리·생산계획조회·재고 관리·관리 다섯 대메뉴를 각각 **조회만 가능 / 모두 가능**으로 설정합니다. 세부 기능별 권한 항목은 만들지 않습니다. 재고 조회는 모든 직원이 이용합니다.

- 입고 관리: 입고 등록·일괄 입고·도착 확인·입고 취소.
- 출고 관리: 피킹 요청·예약·추가 피킹·예약 위치 변경·출고·취소·대체 출고와 상환.
- 생산계획조회: 엑셀 업로드·열 연결 설정·공유 자료 적용.
- 재고 관리: 이동 요청의 승인·실행·거부. 조회만 가능한 직원도 이동 요청 등록·상태 조회와 정리 리스트 조회·인쇄는 가능합니다. 요청·출력만으로 수량은 바뀌지 않습니다.
- 관리: ERP 대조 자료 등록·검토, 직원 계정과 품목 관리. 시스템 책임자는 기존 전체 권한을 유지합니다.

한 대메뉴의 모두 가능은 다른 메뉴 권한을 늘리지 않습니다. 관리만 모두 가능한 직원도 입고·출고를 변경할 수 없습니다. 화면 버튼뿐 아니라 직접 요청과 업무 서비스에서도 권한을 검사합니다. 권한을 회수하면 기존 로그인 세션의 다음 요청부터 적용됩니다.

기존 전체 권한 직원은 모든 대메뉴를 모두 가능으로, 기존 작업자는 모든 대메뉴를 조회만 가능으로 이관합니다. 계정·비밀번호·기존 재고는 재생성하지 않습니다. 새 직원의 기본값은 모든 메뉴 조회만 가능입니다. 직원 삭제 대신 비활성화하며 로그인한 본인의 관리 권한 회수·비활성화와 일반 관리자의 시스템 책임자 변경을 제한합니다.

재고 관리의 모두 가능 직원에게 이동 대기 알림과 건수·대기 목록 링크를 표시합니다. 화면이 보이는 동안 60초마다, 다시 화면으로 돌아왔을 때 갱신하며 완료·거부 건은 제외합니다. 알림 조회는 재고를 변경하지 않습니다.
