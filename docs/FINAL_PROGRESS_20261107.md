## 배포 후 사용자 확인 순서

1. `check` 통과 및 지원 버전 확인.
2. 업무 변경과 인쇄 작업자를 잠시 중지한 뒤 `apply --work-paused` 완료 확인.
3. 새로고침 후 필터·피킹 링크·대체품 등록 확인.
4. 기존 저장 입고 작업과 권한 확인. 실제 필요 작업만 최종 입고.
5. 회사 프린터 설치·외부 접속·1부 종이 출력 확인.

## 별도 현장 진행 항목

- Actas 버튼/정기 수집: 무인 실행 조건과 실제 화면 동작 확인 후 활성화. 이번 수정에서 예약 실행을 자동 활성화하지 않습니다.
- 수주관리 별도 PC의 창 재사용: 별도 개발 대화에서 담당한 부분이며 이번 창고 업데이트의 완료로 간주하지 않습니다.
- 프린터 전송 성공은 종이 출력 완료를 뜻하지 않습니다. 불명확한 인쇄 작업을 자동 재출력하지 않습니다.
- 제외 항목: 수주관리·창고관리 수량 비교 현황, 확정하지 않은 메뉴 명칭 변경.

실제 검사 실행 결과와 소스 버전은 동봉 `VALIDATION.json`을 기준으로 합니다. 현장 확인 전 항목은 완료로 표시하지 않습니다.
