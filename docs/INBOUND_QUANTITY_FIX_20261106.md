# 입고 LIST의 ERP 수량 표기 오류 수정

배포: SUNIL-ERP-20261106-inbound-fix-v1

## 원인과 수정

ERP에서 추출한 CP949 탭 구분 XLS 파일에는 수량이 `6.`·`3.`처럼 소수점으로 끝나는 경우가 있습니다. 기존 수량 검사가 소수점 뒤에 숫자가 반드시 있어야 한다고 판단해 정상 자료를 거부했습니다.

이번 수정은 `6.`을6으로 정확히 처리합니다. `1,200.`, `0.50`, `32.+32.`도 기존 소수 자릿수·범위·양수·분할 합계 조건을 지켜 처리합니다. 음수·0·잘못된 문자·소수점 중복·12자리를 넘는 소수는 여전히 거부합니다. 원본 파일에서 수량을 지우거나 다시 입력할 필요가 없습니다.

실제 첨부 파일은 비공개 환경의 실제 브라우저에서 전체 상세 행·분할·합계를 확인했습니다. 공개 검증에는 같은 숫자 표기를 넣은 가상 자료만 사용합니다. 실제 사용자 파일이나 품목 자료는 배포본에 포함하지 않습니다. UTF8/CP949 및 일반 XLS/XLSX/XLSM, RAW 우선 사용, 기존 복사·엑셀·인쇄·입고 전달 검증을 유지합니다.

선일 ERP 실제 입고는 기존대로 1 이상의 정수 수량을 사용합니다. 정상 소수 자료를 읽을 수 있다는 것과 실제 입고에서 소수를 허용하는 것은 구분합니다. 실제 입고 버튼을 누르기 전 로케이션과 수량을 확인하세요.
