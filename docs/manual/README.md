HTML은 모든 화면 예시를 파일 안에 포함하므로 단독으로 저장해 열 수 있습니다. 화면 예시는 임시 DB·가상 계정으로 생성했습니다. 실제 비밀번호와 업무 데이터는 포함하지 않습니다.

사용자 교육: 일반 사용자는 1~5장을 먼저 읽고, 관리자 업무는 담당자 교육 후 사용하세요. 실습은 운영 재고와 분리된 시험 환경에서 진행합니다. 실제 접속 주소·문의 담당자·실물 이동 시점 등 현장 운영 규칙은 회사에서 확정해 안내하세요.

이 문서는 설치 프로그램이나 실제 DB 백업이 아닙니다.

최신 계정 생성·권한 부여 절차는 [직원 계정과 권한 설정](../ACCOUNT_PERMISSIONS.md)을 참고하세요. 조회 전용은 이동 요청을 포함한 모든 변경이 금지됩니다.
