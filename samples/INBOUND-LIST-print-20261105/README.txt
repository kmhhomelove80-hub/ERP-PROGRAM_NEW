입고 LIST 인쇄 양식 검토용 샘플입니다.

실제 회사 재고가 아닌 가상 품목·수량·위치를 사용했습니다. ERP 프로그램과 DB는 수정하지 않았습니다.

inbound-list-sample.pdf: A4 세로 1페이지, 8품목 13행, 수량 합계 254.
inbound-list-multipage.pdf: A4 세로 2페이지, 표 헤더 반복과 분할 그룹 유지 확인용.

표시 열: 품목코드 / 품목명 / 수량 / 총수량 / 비고. 규격은 인쇄하지 않습니다.
32+32는 두 상세 행으로 표시하고 총수량 64를 세로 병합했습니다.
같은 코드의 위치는 비고에 동일하게 표시하고 일부 행에는 추가 메모 예시를 넣었습니다.
위치가 없는 품목은 위치 확인 필요로 표시했습니다.

Chromium의 인쇄 기능으로 PDF를 생성하고 A4 크기·페이지 수·반복 헤더를 확인했습니다.
실물 프린터 출력이나 실제 ERP 붙여넣기를 검증한 것은 아닙니다. 이 샘플에는 변환/복사/편집 기능이 없습니다.
