Actas 조회 신호 측정 v1

목적
현재 Actas는 조회 완료 문구 없이 재고 표만 바뀝니다.
자동 실행에서 이전 표를 잘못 저장하지 않도록 조회 중/완료 후보 신호를 측정합니다.
이 도구는 조회 완료를 자동 판정하거나 ERP에 자료를 등록하지 않습니다.

실행
압축 안 actas-query-probe-v1 폴더를 기존 업데이트 자료 보관 위치에 넣으세요.
Actas에서 현재고 현황을 열고 창고를 Y02 또는 Y09로 두세요. 저장창을 닫으세요.
Probe-Query.cmd를 실행하고 start를 입력하세요.
12초 안에 Actas로 돌아가 현재 창고 코드 칸을 클릭하고 손을 떼세요.
이후 약 25초 동안 화면 전환·마우스·키보드 조작을 하지 마세요.
마지막으로 Windows 내장 OCR로 창고명 판독 가능 여부를 확인합니다.
측정 종료 후 PowerShell로 돌아와 표시된 결과 경로를 확인하세요.

동작 범위
현재 창고 코드에 Ctrl+R 조회를 한 번 전송합니다.
창고 값을 입력/변경하지 않으며 Ctrl+E·엑셀 저장·대조 등록을 하지 않습니다.
DB 연결·계정/비밀키 읽기·프로그램 설치·설정/서비스/예약작업 변경을 하지 않습니다.
창의 응답·활성 상태·대기 커서와 재고 표 이미지의 지문만 기록합니다.
재고 표 이미지는 디스크에 저장하지 않습니다.
창고 코드와 명칭 판독 검사용으로 검색 조건 영역만 conditions.bmp에 저장합니다.
화면 전체나 ERP 제목줄은 저장하지 않습니다.
OCR은 PC 안에서만 수행합니다. 외부 서비스로 화면을 전송하지 않습니다.
한국어 OCR이 설치되어 있지 않아도 설정을 변경하거나 추가 설치하지 않고 상태만 기록합니다.
다른 화면으로 이동하거나 Windows가 잠기면 측정을 중단합니다.
측정 종료는 조회 완료를 뜻하지 않습니다.

전달할 결과
이 폴더의 runs 안 새 실행 폴더에서 다음 두 파일을 함께 보내주세요.
- query-probe.json
- conditions.bmp
이 실제 측정 결과로 자동 완료 판정과 창고명 확인 방식을 검증합니다.
조건 화면 파일은 현장 확인 자료이며 공개 배포물에 포함하지 않습니다.

정기 실행 예정 규칙
한국 시간 월~금 09:00~17:00 매시 정각, 하루 9회.
공휴일·대체공휴일·확인된 임시공휴일 제외, 이전 작업 진행 중에는 중복 실행 안 함.
확인할 수 없거나 갱신되지 않은 휴일 정보로는 정기 실행하지 않음.
현재 이 도구는 예약 작업을 생성하거나 활성화하지 않습니다.
