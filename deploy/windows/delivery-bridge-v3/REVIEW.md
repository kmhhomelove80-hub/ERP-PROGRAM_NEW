# 검토 결과

처음 전달한 `sunil-erp-bridge-patch.zip`은 현재 운영 v3에 그대로 적용할 수 없습니다.
원본 파일 해시는 `1050987ba0f20db6ec8c37c9003d6090c8192d208814992e07436db2901672b7`입니다.

## 확인된 문제

- 기존 파일 5개가 v3와 다릅니다. 원본 설치기는 `inventory/forms.py`에서 중단했고, 이때 파일이 바뀌지 않은 것을 격리 시험에서 확인했습니다.
- 강제로 덮어쓰면 현재 주소 연결이 사용하는 `movement_notifications` 함수가 사라져 서버 시작 검사가 실패합니다.
- 기존 직원별 메뉴 권한 검사, 신규 품목 입고, 수동 위치 배정, 추가 피킹, 예약 위치 변경, 정리 목록, 이동 알림, 매뉴얼과 메뉴 구성이 이전 상태로 돌아갑니다.
- 원본 설치기는 서비스 상태 점검·DB 백업 검증·재시작 후 검사와 복구 절차가 포함되지 않은 단순 코드 복사 도구입니다.

## 수정본 처리

- 현재 v3를 기준으로 수주 연동 변경만 결합했습니다. 기존 메뉴·권한·기능은 유지합니다.
- 기존 6열 고객 입력을 유지하면서 7열의 합계를 참고 정보로 보관합니다. 예약에는 행별 수량만 사용합니다.
- 수동 위치 배정을 거쳐도 원본 고객 행과 회신 정보를 유지합니다.
- 미리보기에서는 예약하지 않으며, 예약 확인 후 확정된 배정·부족 결과를 회신합니다.
- 같은 전송 번호 재요청은 기존 결과를 반환하며 중복 예약하지 않습니다.
- 이전에 검증한 표준 업데이트 도구를 그대로 사용합니다. v3 파일 해시가 다르면 반영하지 않습니다.
- DB 구조 변경은 없으며, 실제 업데이트 전후에 기존 업무 데이터 보존 검사를 수행합니다.

## 남은 현장 확인

ERP 쪽 수신·예약·회신 처리는 합성 자료로 검사합니다. 별도 수주관리 프로그램의 실제 송신 화면과 양방향 동작은 현장에서 확인해야 합니다.
업데이트 후 먼저 전송 자료 자동 입력과 배정 미리보기까지만 확인하세요. 확인 목적으로 실제 재고나 예약을 임의로 만들지 마세요.
회신은 예약 등록 시점의 결과이며 이후 취소·실제 출고·추가 피킹을 소급 반영하는 기능은 이번 범위에 포함되지 않습니다.

Actas 조회 측정과 버튼·정기 수집 자동화 작업은 보존하며 이번 수정본으로 변경하지 않습니다.
