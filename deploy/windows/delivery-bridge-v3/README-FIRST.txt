SUNIL ERP 수주 연동 수정본

이 수정본은 기존 SUNIL-ERP-20261104-integrated-v3가 적용된 서버용입니다.
처음 전달한 sunil-erp-bridge-patch.zip의 install.bat은 사용하지 마세요.
새 수정본은 기존 v3 기능을 보존하고 수주 자료 수신·예약 결과 회신만 추가합니다.

현재 ERP 서비스를 수동으로 중지하거나 app 폴더를 직접 덮어쓰지 마세요.
UPDATE-STEPS.md의 첫 단계인 사전 점검만 먼저 실행하세요.
사전 점검은 서비스 중지·코드 교체·DB 변경을 하지 않습니다.
점검 로그와 중복 실행 방지 파일은 만듭니다.
실제 반영은 직원 처리를 잠시 멈춘 뒤 별도 명령으로 진행합니다.

DB 구조 변경·초기화·재이관·새 패키지 설치는 없습니다.
이전에 검증한 표준 업데이트 도구로 백업·코드 복구본·서비스 재시작을 처리합니다.
기존 운영 설정·DB 접속값·직원 계정·Actas 대조 자료는 교체하지 않습니다.
Actas 수집 자동화는 이번 업데이트와 별도이며 예약 실행을 켜지 않습니다.

검토 결과와 남은 현장 확인 사항은 REVIEW.md에 있습니다.
