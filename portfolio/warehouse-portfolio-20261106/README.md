## 시연과 확인 범위

- 실제 프로그램을 임시 로컬 서버와 별도 데이터베이스로 실행해 브라우저 동작을 녹화했습니다. 가상의 품목·프로젝트·위치만 사용했습니다.
- 선택 출고 9행, 입고 파일의 32+32 분할과 사양 포함 5개 항목 전달, 실제 입고 2행 반영을 확인했습니다.
- 실사 수량을 변경하고 사유를 입력해 미리보기·자동 백업·반영·되돌리기를 확인했습니다. 예약 수량 2개를 유지하고 실사 재고를 원래 수량으로 되돌렸습니다.
- 생산계획 검색·행 선택, 재고 정리 기존 유지·판정 이력을 시연했습니다.
- 실사 전 피킹·포장 완료 여부는 사용자가 확인하는 절차입니다. 프로그램이 물리적인 포장을 자동 감지하는 것은 아닙니다.
- 이 영상은 가상 자료의 기능 시연입니다. 처리 시간 단축률, 금전 효과, 회사 운영 환경의 성능 수치는 주장하지 않습니다.
- 회사 로고와 실제 거래 자료를 사용하지 않았습니다. 시연용 상단 이름은 별도 화면 구성에서만 바꿨습니다. 운영 프로그램 소스와 실제 서버는 변경하지 않았습니다.
- 화면의 한국어 자막은 영상 안에 들어 있습니다. 별도 SRT는 편집용이며 재생기에 함께 켜면 자막이 중복 표시될 수 있습니다.
- 실제 대상 ERP에서의 클립보드 붙여넣기·브라우저 인쇄를 이 영상으로 검증했다고 주장하지 않습니다. 영상에서는 자체 입고 화면으로 보내기 기능을 사용했습니다.
